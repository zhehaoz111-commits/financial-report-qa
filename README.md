# 财报问答实验室：作业3 / 方向A

使用10家A股白酒上市公司的**2025年完整年报**，共1,720页，建立带公司、章节和PDF页码的文字/表格知识库。来源为巨潮资讯，原始PDF、披露信息和SHA-256均保留。

## 直接运行

已附带建好的索引，无需安装Python分析依赖、GPU或API密钥。

```bash
python3 -m http.server 8000 --directory dist
```

在浏览器打开 `http://localhost:8000`。不要双击HTML文件，浏览器会限制本地JSON读取。页面包括：问答、财报资料库、10题真实测试记录、方法与局限。首次读取完整文本和索引需要等待；数据在浏览器本地检索。

命令行提问需要Node.js（建议20或更高版本）：

```bash
node scripts/query.mjs "贵州茅台2025年营业收入是多少？"
node scripts/query.mjs "这10家公司2025年营业收入排名如何？" hybrid
```

## 复现资料处理与索引

```bash
python3 -m pip install -r requirements.txt
python3 scripts/download_reports.py
python3 scripts/build_index.py
python3 scripts/fix_chapters.py
python3 scripts/compress_index.py
python3 scripts/build_metrics.py
node scripts/evaluate.mjs
```

下载脚本只选2025年年度报告全文，排除摘要、英文版、审计报告等，核验PDF文件头、年度与最低页数。下载元信息逐公司缓存，重复运行不会重复下载已有文件。网络不可用时可使用已附PDF和来源清单。

`build_index.py`的表格处理需要几分钟。PyMuPDF逐页保留原始单元格，空白格不推测补齐；跨页合并表头和复杂无框线表仍可能出错。`extraction_audit.json`记录空文本页、表格抽取错误等。`extracted/`可逐页检查完整文本与表格行列。

`build_metrics.py`是公开的人工校准步骤：复核10家公司同年度合并营业收入、归母净利润、经营活动现金流净额，以及营业收入同比。每个金额必须在对应PDF页面出现。它不是自动解析指标的算法，也不是隐藏答案库。

## 方法

1. 每页文字按约950字切块，100字重叠，不跨页。章节通过PDF标题的位置校准；一页中途换章节时，按表格位置或文字范围分配，跨章节文字块明确标记两个章节。
2. 表格按10行切块并重复前两行，保留原始行列、页码、表格位置。
3. BM25：中文双字词、英文与数字词元，k1=1.5，b=0.75。
4. 向量：TF-IDF → TruncatedSVD → 64维LSA，余弦相似度。
5. 按问题类型做通用结构路由：数值定位优先主要财务指标章节；原因题优先包含对应指标及原因标记的段落。未找到结构候选时回退全库。再将两路前150名以RRF（k=60）融合；跨公司问题对每家公司分别召回。
6. 默认回答为**原文抽取**。少量已核验数值由指标卡回答，页面另列原始召回，区分检索能力和人工校准能力。

LSA是可复现的本地潜在语义向量基线，**不是预训练Embedding模型**。项目实现了向量索引+BM25；与现代中文Embedding的效果不能混为一谈。

## 可选大模型生成

页面导出本次问答JSON后，可使用`generate.py`，由用户自己的服务归纳检索证据。设置`QNA_API_URL`（完整、兼容的chat-completions接口地址）、`QNA_API_KEY`、`QNA_MODEL`后运行：

```bash
python3 scripts/generate.py 财报问答记录.json
```

密钥仅通过环境变量提供，不写入页面或仓库。脚本检查引用的片段ID确实来自检索证据；引用存在不等于事实正确，仍须核对原文。**本次没有调用该可选接口，也没有训练、微调或评测生成式模型。**

## 测试与交付

`test_questions.json`包含10道题及独立手写的参考答案。其中Q08、Q09、Q10为跨公司题。`dist/evaluation.json`记录逐题实际回答、片段ID、公司、章节、页码、BM25/向量排名及判定原因，`evaluation.csv`便于表格查看。

测试是同一资料集上的课程功能验证，数值题含人工指标校准，不能据此宣称大模型准确率、独立留出集效果或无人工介入的财报抽取效果。召回命中和最终回答分别记录。Q08的全景归纳需人工评价，自动脚本仅复现已记录的评审判定。

`experiments/`保留未加结构路由的基线引擎和实际评测，便于解释检索失败。可运行`node scripts/evaluate.mjs --baseline`重现基线，不覆盖最终评测。结构规则经过本批测试题启发，效果不能当作未见问题的泛化结果。

提交时包括：代码仓库/完整项目包、实际页面截图、10题测试记录、一页结论。截图和结论位于交付附件中；完整项目还包含原始PDF与来源清单。

## 资料口径与局限

- 页码统一为PDF文件页序，可能与页脚印刷页码相差一页。
- 营业收入采用合并公司口径，不等于白酒业务收入。
- 本期、上期、元与亿元需逐项核验；数值展示统一给出元和亿元。
- 财务公司等合并范围差异会影响经营现金流，不能直接据此断言公司经营质量。
- 2025年年报之外的未来实际数据拒答；比较年度数据可能出现在年报中，但不使用2025指标卡冒充其他年度。
- 没有OCR管道，扫描页需另行补充；复杂表格和因果解释仍需人工核对。
- LSA偏向本资料集的共现词，长问题、同义改写和跨公司全景归纳可能召回不佳。
- 原始财报属于公开披露文件，归各公司所有；本项目用于课程作业与研究学习。
